# zg-frames block catalog

Auto-generated by `catalog.mjs`. One archetype per section. Mount a block in a
live video with `data-composition-src="blocks/<name>/<name>.html"` and pass the
variables below via `data-variable-values` on the slot. Timing comes from the
`data-sent` anchor + `stamp-timing.mjs`, never a hand-typed number.
